# 杭州宝宝疫苗接种日历

可由 iPhone **订阅并持续更新**的儿童疫苗接种参考日历（公开、只读）。

- 适用接种计划：2026 年 11 月至 2032 年 11 月，共 30 项参考日程。
- **全部接种提醒安排在周一至周五**，不代表门诊当天开诊；未排除中国法定节假日或社区门诊特殊排班。
- 每项日程标注推荐疫苗、剂次及部分费用提示；注射针数尽量不超过两针，口服疫苗不计针数。
- 所有日程均为**接种计划**，不代表已预约，更不代表已完成接种。
- 仓库不含姓名、证件号码、地址、联系方式；但接种日期可间接推算出生日期，故请勿添加个人隐私。

## iPhone 订阅

复制这个**固定的原始 .ics 地址**：

https://raw.githubusercontent.com/HughZhou-Top/hangzhou-baby-vaccine-calendar/main/vaccination-calendar.ics

在 iPhone「日历」App → 底部「日历」→「添加日历」→「添加订阅日历」中粘贴。

可将日历命名为「宝宝疫苗接种计划」。订阅日历只能查看；在 GitHub 更新同一个 .ics 文件后，iPhone 将在下一次订阅刷新时获取更新，刷新时间由系统决定，可能存在延迟。文件内设置提前 7 天和 1 天提醒，但客户端可能不显示订阅日历提醒，重要疫苗请另设置提醒事项。

## 维护方式

1. 修改 `events.json` 中对应条目的 `date` 或 `description`。
2. 保持 `id` 不变（维持订阅事件的稳定身份）。
3. 执行 `python3 build_calendar.py` 生成新的 `vaccination-calendar.ics`。
4. 将 `events.json` 和 `vaccination-calendar.ics` 一并提交至 `main` 分支；**订阅 URL 不变**。

脚本验证周末和单次注射针数（不超过 2 针），但不自动核验法定节假日、各种疫苗的最低剂次间隔或产品说明书的年龄窗口，请由接种门诊审核。

## 重要医学说明

这是一份参考提醒，不是医生开具的疫苗处方。出生首针、既往接种记录、不同厂家的替代程序、轮状病毒首剂年龄窗口、流脑结合疫苗替代及免疫异常等，均须由杭州接种门诊依据最新版国家程序及实际在用疫苗核对。计划日期遇门诊停诊，应先核对最小间隔和年龄截止日再重新安排。
